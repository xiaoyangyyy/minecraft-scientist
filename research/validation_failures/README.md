# Promotion failure diagnostics

Evaluator-only raw-table minimum-cost counterexamples explain incorrect finite
validation promotions in the complete development probe. This is not an Agent
planner: the diagnostic has after truth and must never provide its actions to
learning, monitoring, candidate generation or a fair method baseline.

The diagnostic requires the completed public-first/raw audit receipt and pins
every campaign artifact. It retains all incorrect promotions, reconstructs the
actual final validation words, and compares their coverage with a bounded
minimum-cost witness. Remaining budget establishes only affordability WITH an
oracle; it does not prove a feasible blind Agent would find that witness.

The raw product/cost search does not call an IR compiler. Tests use independent
exhaustive action-word enumeration with nonuniform costs and finite horizons.
The first unregistered probe exposed seven sentinel-queue defects; that XML is
retained and not counted as a passing test. The queue now processes mismatches
at pop time, preserving cost/length/word order. Register before final tests.

This analysis is restricted to development. It does not repair the prospective
validator, solve unknown control/noise, certify unique causal structure, or
close H4/Minecraft/RGB/release requirements.
