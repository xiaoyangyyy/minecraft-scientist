# Generated-structure development campaigns

The common paid lifecycle now has an adapter for independently constructed
structural fixtures. This directory is DEVELOPMENT integration, not a formal
held-out learner evaluation or a claim of novelty.

The loader requires the SHA-256 of a construction manifest already checked by
the independent corpus audit. It reads the pinned partition and selects only
development groups. A group limit selects complete lexicographically first
groups, never easy cases. All selected public entries are validated before any
private fixture read. Tuning/evaluation fixture files are inaccessible through
the corpus capability and never opened by this runner.

Four methods share public prior factors, paid bootstrap, monitoring, the
prospective validation reserve and version promotion protocol. The learner
receives only AgentWorldView and public config. IDs, groups, metadata, private
boundary and after tables are runner/Evaluator-only. Structured methods have a
declared edit bias; general finite-state methods have a different language.
This is not a same-candidate planning comparison.

Runs freeze config and output before scoring, independently replay raw compound
tables, keep proposed/promoted correctness separate, and retain every failed,
wrong, undetected and unresolved outcome. Runtime source hashes and complete
groups are registered before learning. Timings are excluded from deterministic
replay. Partial failures retain evidence without a certified manifest.

Default covers all development groups. Use `--max-groups 1` only as a declared
compatibility probe, not a statistically adequate sample. Do not adjust method
parameters on the sealed splits. Unknown controllers, noise, non-reset worlds,
formal sample design/strong baselines, H4 and Minecraft/RGB remain open.

```powershell
uv run python scripts/run_structural_development.py --corpus runs/structural-corpus-development-windows-v1 --manifest-sha256 8399037d3a09062d9b74134779c35d4a8f75a0eb8f1b9ffb9d10cec3eb77fc8c --output <new-directory> --max-groups 1
```
