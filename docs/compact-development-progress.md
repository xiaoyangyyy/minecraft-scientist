## 存储操作与限制

两个已退出的聚焦测试目录做了 NTFS 压缩，未删除文件或移动恢复路径。
Windows 709 个文件的内容哈希在压缩前后匹配。Linux 目录还包含 17 个
pytest `current` 符号链接；初次 PowerShell 核验错误地将它们当文件，出现
不可读告警，这次输出不计作完整保留证明。随后明确排除链接，对 709 个
普通文件使用终止式错误检查重新核验，文件内容未变。链接不参与科学数据
哈希，不将不可读别名当成成功验证。

更大开发矩阵可能出现首组没有的错误晋升、预算耗尽与覆盖缺口。应按完整
分母、结构／泄漏组和实际费用报告，不能用重复／重命名增加独立样本数。
正式样本设计、强随机／LLM／自适应基线、未知控制／噪声、符号迁移和负迁移、
受控 Minecraft、自然 RGB、导航、恢复和发布仍然开放。
