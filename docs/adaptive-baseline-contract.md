# 强基线适配契约：主动自动机学习与科学修订

状态：完整强基线实现/验收契约。基础 L# 从头结构学习适配已接入并通过
聚焦审计，见 `active-automata-development.md`；它没有完整 Adaptive L# 和
原文 conformance 测试器，不算强基线矩阵完成。当前 H3 仅比较见证覆盖与多步 IG；
此文件不把它们替代从头结构学习、自适应学习或公平 LLM 基线。

## 已核对的一手方法边界

[L# 原文 §3.2/§4](https://arxiv.org/html/2107.05419v4) 使用观测树、状态
apartness 和反例处理；实际实验用基于输出查询的 conformance testing 近似
等价查询，计入学习与测试的输入和复位成本。因此，忠实适配不需要把私有
真值 oracle 免费给基线，也不能把原文简单描述成只能在免费 oracle 下运行。

[Adaptive L# 原文 §5/§6](https://arxiv.org/html/2406.19714v1) 使用参考模型
的状态匹配来复用区分序列，支持近似匹配及多参考。复用旧状态机和生成区分
实验不是本项目独有能力，不能作为独立创新声明。

以下内容是本项目拟定的公平性与接口要求，不是声称这些论文已处理本项目
全部隐藏控制器、在线非平稳或科学归因条件。

## 三个不能混合的比较条件

1. 纯实验规划：候选空间、先验、公开历史、查询时域与预算完全相同，比较
   witness/多步 IG/随机/小规模最优参考。候选生成在此条件不评分。
2. 行为结构学习：所有方法取得同一动作/输出字母表、旧科学联合理论及允许
   的公开先验；比较生成出的可执行行为程序。结构语法或先验不同必须单列，
   不能把额外有限候选知识带来的收益说成纯算法优势。
3. 因子归因：行为正确与机制/控制器分离分别评分。若基线没有控制器族信息，
   不把它无法输出因子身份当作方法失败；增加知识匹配的因子投影条件，保留
   歧义而不从私有状态选择解释。

## 输出查询契约

输出查询通过 AgentWorldView.begin_trial()/step() 真实执行。每个输入、复位、
失败或重试都记账；对已取得公开前缀的缓存读取不假装成新的独立实验。
预测或查询目的在 dispatch 前冻结，不能读取原始世界或评测私有文件。
记录观测树及证据 lineage，处理已知控制失败时不把失败输出写成机制观测。
未知控制送达仍是潜变量，不能因为接口返回 success 就宣布处理水平已确认。

在线变化后不能无条件沿用旧时代的观测作为新世界 membership 答案。旧程序
可以作为公开参考知识；查询缓存必须有 epoch 与证据作用域。混入旧状态
导致的矛盾、刷新成本和错误旧知识迁移都必须成为指标。

## 等价检查契约

替换为预先声明、同预算的真实 conformance 查询协议。若找到反例，可供下一
候选学习，但该查询随后属于 discovery，下一候选必须重新取得独立验证。
未找到反例只给出有限协议下的验证结论，不能搬用无限 MAT 精确收敛保证。
测试支出与学习支出都进入总预算，不给任何方法免费私有反例。

独立 Evaluator 可以在冻结后穷举 H 内行为评分，这不是学习器的 equivalence
查询。任何把此评测功能回传规划器的路径必须在隔离测试中被拒绝。

## 忠实性、计算成本与验收

实现必须覆盖原方法的关键规则、状态区分、假设构建、一致性和反例处理，并
以人工小程序和独立参考验证。如果只实现参考区分序列排序，应明确命名为
reference-sequence heuristic，不能冠以完整 Adaptive L#。

不能单靠当前四状态模板调出有利规则顺序。正式比较要先冻结结构划分、
变化组合、查询/计算预算、验证协议、停止规则、方法代码和分析脚本，再使用
未参与调参的结构。固定模板重命名及相同 seed 重跑不算新样本。
记录全部查询、复位、原子动作、CPU/时间、缓存和搜索数量；运行时间独立保存，
不进入确定性事件/理论比较。硬预算截断、不可执行与未解决必须保留。

验收包括逐步策略重放、公开预测与账本、私有读取隔离、持有缓存的时代
一致性、预算负例、行为/归因覆盖以及 Windows/Linux 复现。当前这些基线
验收仍未完成；H3 留出与 H4/Minecraft/RGB/全项目发布目标继续保留。
