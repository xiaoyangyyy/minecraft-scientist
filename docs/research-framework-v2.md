现有实现见 `architecture.md`，历史结果见 `research-report.md`，完整项目验收边界

## 1. 研究定位

核心问题：一个自主智能体能否在未知世界中，通过预算受限的有效干预，发现、
区分并修订可执行的因果机制，并将经过验证的知识迁移到新实例？

Minecraft 是可交互实验世界与最终系统验证载体；视觉导航是证据获取模块，
不是第一阶段的方法贡献。未知指隐藏的规则、参数、状态或结构未知，不意味着
Agent 完全没有动作契约、候选语言和先验。每项实验必须公开这些先验。

三个核心能力：

- Mechanism Discovery：输出能执行、能预测未见干预的规则、状态机、方程或程序，
  不以一段自然语言解释或训练样本拟合代替机制证据。
- Interventional Discrimination：保留竞争理论，寻找有区分力的动作或动作序列，
  并正确报告预算不足、不可执行或不可识别。
- Theory Revision & Transfer：区分执行问题与理论问题，修订参数、适用范围或结构，
  在独立验证后替换旧版本，并验证迁移收益与负迁移。

符号学习贯穿上述能力，但属于经验证的机制复用，不另开一套与因果实验脱节的主线。

## 2. 相关工作与创新边界

预算受限的因果实验设计已有成熟研究，例如
[ABCD-Strategy（AISTATS 2019）](https://proceedings.mlr.press/v89/agrawal19b.html)。
因此，信息增益或主动干预本身不是本项目的新贡献。

[ReplaySCM（2026，预印本）](https://arxiv.org/abs/2605.08197) 已使用受限 Boolean DSL
评估可执行机制的留出干预重放，也包含训练证据兼容的替代理论与区分干预任务。
因此，“可执行机制 + 竞争理论 + 区分干预”这个组合本身不能直接宣称创新。

[Causal Discovery in Action（CLeaR 2026）](https://arxiv.org/abs/2603.22620)
研究具有特定链式结构假设的系统及阻断干预下的识别。这也提醒我们：识别结论
依赖明确的世界结构和允许干预，不能外推为任意动态环境的唯一因果恢复。

本项目拟验证的差异在于：部分可观测、带隐藏状态的序贯可执行机制；真实控制
不一定实现预期干预；规则变化后需要区分控制故障、参数变化与结构变化；复用
必须在独立实例中成立。这是贡献假设，不是已证明的原创性。正式方法定稿前
仍需进一步核对相关方法与基准，不能以“结合了多个模块”代替方法贡献。

新增核对：[L# / Apartness](https://arxiv.org/abs/2107.05419) 已涉及主动自动机
学习与区分序列；[ACDB（2026-09 预印本）](https://arxiv.org/abs/2609.31675)
已评测预算受限的 LLM 主动因果发现。因此，基础有限状态见证搜索和预算基准
也不直接作为创新。上述核对不是完整相关工作综述。

H2 实现后的进一步核对：[Diagnosability Planning（AAAI 2017）](https://ojs.aaai.org/index.php/AAAI/article/view/10694)
已在给定正常/故障模型的部分可观测系统中搜索使系统可诊断的动作计划；
[Adaptive L# / State Matching（FM 2024）](https://arxiv.org/abs/2406.19714)
已通过参考模型结构降低主动自动机学习的样本成本。因此，已知故障模型的
主动诊断、旧模型复用及版本改变后的重学也不能单独算创新。下一阶段应纳入
适配后的自适应模型学习基线，明确其查询/等价检查假设与本项目真实实验成本
的差别；不能把免费真值反例 oracle 当成可实现的 Agent。
H3 的实现契约见 `structural-revision-design.md`，受限开发结果另见
`revision-development.md`；二者都不是原创性或完整 H3 已完成的证明。

## 3. 问题定义与可识别性

每个理论 T 包含状态更新程序、观测/结果预测、前置条件、适用范围和必要的
噪声参数。理论通过受限解释器执行，不允许任意文件读取、网络、eval 或隐藏
评测器调用。动态理论维护潜状态或潜状态信念；潜变量不等于可观测真值。

令 H 为 Agent 已取得的公开历史，W 为预先声明的初始观测协议，U 为允许的
干预序列集合，c(u) 为干预成本，B 为总预算。需要区分三种概念：

- 数据一致：T1、T2 都能解释有限历史 H；这不证明完整观测分布相同。
- 协议观测等价：在 W 定义的观测/常规操作条件下，两者给出相同公开结果分布。
- 允许干预等价：在 U 的全部允许干预下，两者都无法区分。

核心任务是在观测等价但干预不等价的实例上找出 u*，满足：

    c(u*) <= B
    P_T1(Y | H, executed(u*)) != P_T2(Y | H, executed(u*))

噪声环境不能用一次结果不相等作为区分证明；必须预先规定预测分布、区分阈值、
重复样本和停止规则。Agent 的动作不是天然的完美 do 干预：只有执行与目标变量
改变经过适当检查，才能赋予相应的干预解释。检查不充分时保留不确定性。

若不存在允许的区分干预，应输出当前作用域内的等价类；若区分存在但预算不足，
应输出未解决。不得把某个排序靠前或描述较短的候选称为唯一真实机制。

“最小干预”限于已声明的成本、上下文、动作语言与最大时域。在小规模确定性
任务中枚举最短区分序列；多理论自适应任务比较相同先验下的最优实验决策树。
噪声任务采用已验证的界或明确标为近似参考。参考策略不能提前知道实际真值，
否则只能标为额外的知真值下界，不能与可实现策略混称。

## 4. 可证伪假设

| 假设 | 需要的证据 | 什么结果否定该假设 |
|---|---|---|
| H1 序贯区分 | 对单步结果相同但多步结果不同的理论，找到有效且成本较低的见证序列 | 与相同候选、先验和计算预算的贪心信息增益相比没有可靠收益 |
| H2 执行与理论分离 | 在规则不变的执行故障条件下避免错误理论修订，在真正变化时及时修订 | 大量误报变化，或通过拒绝绝大多数样本获得表面低误报 |
| H3 结构修订 | 对超出旧参数族的变化，提出并验证新结构，恢复未见干预预测 | 仅重估旧参数、记忆反例或重置全部知识也达到相同结果 |
| H4 验证后迁移 | 在新 ID、参数变化及未见组合中减少总成本，且错误不增加 | 收益仅来自重命名实例、固定人工程序或更宽松预算 |

H1 是首个主实验；H2/H3 是下一阶段重点；H4 在前三者获得可靠证据后展开。
假设可以被否定。负结果需要报告与分析，不得通过更换测试集或成本口径隐藏。

## 5. 系统架构：一套共享 IR、两个工作循环

快循环负责取得有区分力的证据：读取公开历史，维护竞争理论和状态信念，
提出候选干预，冻结各理论预测，执行动作序列，核对执行与测量，更新版本空间。

慢循环负责理论与知识版本化：分析反例，提出参数/范围/结构分支，在新的
验证实验上影子测试，晋升新版本；从验证后的程序中提取符号，再独立验证复用。

| 模块 | 输入与输出 | 关键约束 |
|---|---|---|
| World Boundary | 公开观测、可行动作、执行回执 | Agent 不接收 GroundTruthSpec；评测回传不用于动作选择 |
| Evidence Ledger | InterventionSpec、TransitionRecord、冻结预测、失败记录 | 请求、实际执行、可验证处理水平和结果分别记录；不回写历史 |
| Executable Theory Runtime | TheoryIR 与公开上下文，输出预测分布和状态更新 | 统一规则/状态机/方程/程序解释；有资源限制与类型校验 |
| Hypothesis Manager | 有限候选或受限程序语法，输出竞争理论及等价类 | 声明先验与覆盖范围；缺少真值候选时不能强行选一个 |
| Discrimination Planner | 竞争预测、状态信念、成本/风险，输出区分实验 | 比较行为等价类而非语法数量；考虑可执行的多步序列 |
| Experiment Executor | 冻结干预计划，输出实际轨迹与合规性 | 复位、等待、重试和失败均计入成本；无法确认则保留未知 |
| Revision & Registry | 反例和诊断实验，输出版本分支与状态事件 | 不原地改写理论内容；检测、修订和晋升是不同事件 |
| Symbol & Transfer Library | 验证程序，输出参数化 primitive 和复用记录 | 符号定义本身计入编码长度；独立验证与负迁移检测 |
| Independent Evaluator | 私有世界规则和冻结产物，输出审计及指标 | 仅在动作/理论冻结后评分；行为重放不靠名称或 IR 字符串相等 |

导航适配器与上述科学内核通过 World Boundary / Executor 相连。它负责到达
实验地点和提供观测，不直接决定哪条因果理论正确。到达失败、感知歧义和
干预失败必须进入证据账本，不能被当作环境规律的反例。

候选生成分为两个明确阶段：

- 已知候选族识别：所有方法得到相同候选、先验和初始证据，单独测量规划能力。
- 结构生成：所有方法得到相同受限 DSL、类型与长度预算，不提供真实结构；
  搜索规则组合、状态转移、前置条件或程序组合，再验证可执行性和行为。

第二阶段是在声明语法内生成新结构，不等于无限开放的机制发明。若真实机制
不在语法内，要报告模型失配；还应测量候选召回与搜索计算成本。

## 6. 拟验证的方法，而不是给旧信息增益换名字

保留现有成本/执行风险感知的信息增益作为强基线。新规划研究优先验证：

1. 对语法不同、当前允许行为相同的理论去重/分组，避免表示冗余放大熵。
2. 搜索短序贯见证：单步无区分力时，考虑准备、启动、等待、取出等组合。
3. 在规定先验下估计实验后剩余行为歧义，同时计入执行、复位、测量和失败成本。
4. 优先寻找反驳当前高置信理论的实验；不能只选择最容易确认它的实例。
5. 保留执行失败模型与环境机制模型的竞争解释，按诊断证据分别更新。

每项能力逐项消融；也设置匹配时域的多步信息增益参考，避免把“允许更多步”
误称为新方法收益。若只实现现有单步熵排序，则方法仍是现有信息增益基线。

理论异常先并行考虑执行未实现、测量不可靠、参数变化、范围变化、结构变化，
不能仅凭一个异常宣称规则突变。可验证的控制失败不淘汰世界理论；不确定的
失败需要诊断或建模，不能全部静默删除。独立报告丢弃率及选择偏差风险。
新版本必须在未用于产生它的实验上验证，并保持其声称作用域的旧知识兼容性。

## 7. 首个主实验：观测孪生机器

在受控、可复位的小世界中构造两个执行机制：

- T1：装载后必须启动；随后 WAIT 才能生成产物。
- T2：装载已满足加工前提；启动只改变可见指示，不决定是否产生结果。

初始常规序列“装载、启动、等待、取出”的所有公开轨迹相同。基准明确规定
加工进度由 WAIT 推进，并让其他公开特征一致；私有状态可以不同。
可能的区分序列是“装载、等待、取出”，但 Agent 不接收这个答案。

发现阶段只提供常规证据与相同动作契约。Agent 必须自己保留/生成替代理论，
提出序列并在执行前冻结不同预测。独立 Evaluator 枚举小任务确认观测等价、
区分见证与最小成本。这个简单实例用于协议校验，不足以证明方法普遍有效。

正式任务包含阈值工具、延迟/隐藏状态机器、分支/组合转换程序与局部数值规律。
不是所有任务都保证有可行区分解：必须加入不可识别、预算不足、部分序列
不可执行、机制不在候选族内，以及控制故障但规则未变的负例。

## 8. 实验矩阵与比较公平性

正式运行前冻结任务生成器、结构模板划分、预算、先验、动作时域、停止规则、
指标、分析脚本和源码哈希。开发/调参/最终评测的结构与实例都需要分离；
单纯更换 seed 或 opaque ID 不构成结构泛化。

| 维度 | 必须区分的条件 |
|---|---|
| 可识别性 | 观测可识别；需干预；需多步干预；允许动作内不可识别 |
| 模型知识 | 同候选族识别；同 DSL 结构生成；超出 DSL 的模型失配 |
| 规则变化 | 无变化；参数变更；上下文/范围变更；结构变更 |
| 执行与测量 | 确定性合规；已知执行失败；隐藏执行失败；观测噪声 |
| 迁移 | 仅换 ID；参数改变；未见结构组合；带负迁移风险的目标世界 |

主要基线：所有合法动作均匀随机；现有 informative-random；同候选贪心信息增益；
成本/风险感知信息增益；匹配时域的多步参考；LLM context-only 与 LLM 文本记忆；
完整方法。小任务增加最优决策树参考。符号比较包含无库、人工固定库与学习库。

LLM 与符号方法若候选知识不相同，要另列端到端条件；不能把知候选的符号后验
与无候选的 LLM 当成纯规划能力比较。固定模型版本、提示词、温度、工具权限、
输入证据和重试规则；保存 token、费用、时延、失败及全部调用。默认离线路径
不依赖 API Key；本框架不授权使用任何已暴露或已撤销的密钥。

预算同时报告实验次数、原子动作数、复位/等待/重试、实际执行失败、推理计算
以及外部调用成本。各方法上限一致，实际支出分别报告；验证与符号复用成本
也计入。不得只给完整方法提供免费复位、额外证据或隐藏候选。

建议每个主条件至少 30 个独立世界，再按预注册的效应量/精度进行样本量设计；
30 不是统计保证。按世界/结构模板配对分析，报告区间、失败分布和原始逐实例
结果。重复同 seed 是回放验证，不是新的独立样本。预算耗尽计入失败或未解决，
不可执行与不可识别单列，并报告总体覆盖率，不只汇报成功子集。

## 9. 核心指标与研究验收

| 能力 | 指标 |
|---|---|
| 机制发现 | 独立未见干预上的执行预测误差/准确率、概率校准、候选覆盖 |
| 理论区分 | 预算内消除错误行为类的比例、首次有效见证成本、相对参考成本 |
| 边界认识 | 错误宣布唯一识别率、不可识别正确报告率、未解决率与覆盖率 |
| 理论修订 | 无变化误报率、变化检测延迟、修订成本、独立验证后的预测恢复 |
| 知识保持 | 新版本作用域内的旧干预回归、被替代/保留的理论与证据 |
| 符号迁移 | 新实例总成本差、行为误差、负迁移、含定义成本的 MDL 差 |
| 工程与审计 | 确定性回放、隐藏真值隔离、预测冻结、独立审计、全部失败记录 |

执行预测准确不等于唯一结构识别；原始潜状态标签也可能不可识别。主要评分
采用声明作用域的行为，结构评分只在基准证明可识别时使用。MDL 是复杂度准则，
不是因果真值证明。理论语言和编码器固定后才能比较描述长度。

研究阶段的交付应包含完整可重放基准、方法与强基线、预注册统计分析、正负例、
失败解释和受限结论。不得为了获得“胜过所有基线”的结论更换口径；如果假设
未获支持，应如实报告并据此决定后续研究，而非宣称已证明方法贡献。

## 10. 三层验证，不混用结论

- A：结构化微世界。隔离科学算法，验证可识别性、区分、修订、迁移与预算。
- B：受控 Minecraft 实验。检验真实动作执行及观测是否支持同样的机制结论；
  标明 fixture 提供的位置、对象身份、复位和动作帮助，不能称 RGB 自主探索。
- C：自然世界 RGB 自主科学家。自己找到实验地点、取得可靠证据、修订理论，
  并跨地点复用；独立验证实际到达、感知、执行及科学结果。

A 的成功不等于 B，B 的成功不等于 C。C 仍需原路线图中至少五个额外独立世界、
多地形/三种条件、至少 100 次探索或实验尝试、重启/注入故障恢复、配对比较与
整合发布证据。导航不足不能由离线科学结果抵消。论文阶段结论与项目端到端
完成状态必须分别标明。
