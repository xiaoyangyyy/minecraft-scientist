# 付费旧模型学习与配对上下文迁移：开发阶段 v3

日期：2026-10-09。本阶段实现位于隔离的 `research/adaptive_automata`，
不修改正在进行 Linux 默认全量回归的主包及默认测试。它推进公平强基线的
实现与验证，不宣称 H3/H4、创新贡献或 Minecraft/RGB 端到端目标已经完成。

## 这次真正改变了什么

此前静态原型的参考模型由 runner 免费提供，不是自主学习的旧知识。
当前 `paid_transfer.py` 首先用零参考模型的同一学习器，从公开交互中学习旧
上下文，并支付复位、原子动作及新验证实验的成本。只有有限验证通过，才能
发布旧理论。双方取得完全相同的旧历史/理论，并承担相同的旧学习支出。

随后明确切换至新上下文：adaptive 以已发布旧 IR 为参考，from_scratch 是
刻意忽略参考知识的消融。两者共享动作/输出契约、总预算、时域、种子及
H 条件化随机 Wp 验证程序。没有额外免费真值反例，也不把旧轨迹写入新树。
新上下文预算是总预算减去实际旧学习支出，不是另发一个完整实验预算。

旧学习预算上限 120，总预算 360，最大查询时域 H=5，每个最终验证批次
8 次实际新查询。观察树和参考搜索分别有 200000 次访问上限；这不是完整
CPU 成本界。两阶段学习/验证/注册表与完整审计的实际 CPU/墙钟时间分开
保存在 `timing.json`，不参与确定性比较，也不包括全部启动/序列化成本。

## 版本、验证和隔离

旧/新上下文分别具有自己的查询缓存和 `old-context`/`new-context` 证据 ID。
TheoryRegistry 为每个通过有限验证的理论记录 proposed → provisional → accepted
快照，并保留新版本的父版本。最终批次的证据与生成该候选的 discovery 证据
不相交；失败验证回流后，下一候选必须重新支付新验证成本。

这里 accepted 仅表示明确上下文内的有限批次通过；不是唯一因果结构、全 H
行为认证或概率校准。confidence 的存储值 0 明确标为“未估计”，不是成功
概率。私有评分仍可能揭示错误，必须保留而不能称其为无效运行。

上下文切换是已知的，不是未告知 Agent 的在线突变。因此旧上下文理论不被
虚构为 challenged/superseded；真实在线危机、诊断、影子验证和替换仍有独立
验收门槛。本阶段也不是从程序中学习参数化符号的 H4 库学习实验。

`audit_transfer.py` 先分离输入快照，在读取任一私有文件前完成两个上下文的
原始公开账本检查、参考来源/剩余预算检查、理论谱系及完整策略重放。第二
上下文若有伪造记录，不能先读取旧上下文私有表。快照防止第一次私有读取
回调篡改第二上下文的被审计输入。之后才独立评分每个上下文 H 内的行为。
策略重放仍使用同一学习器；独立原始检查针对已测试共享缺陷，不是无缺陷
证明。未知送达、混杂、噪声、自然连续执行及因果因子归因不由它认证。

## 配对开发结果与负迁移

任务为 seed 0/1 × dense/sparse/cycle/branch × 新状态数 2–5，共 32 对、
64 次完整两上下文运行。旧世界为两状态 cycle，但其真值表不传给学习器。
物品/动作/输出为稳定匿名 ID，Agent 不取得生成器的 family/state count 标签。
这是固定生成器上的开发网格，两个 seed 不支持正式统计或结构泛化结论。

| 结果 | 从头学习 | 参考模型自适应 |
|---|---:|---:|
| 两上下文 H 内行为正确 | 19/32 | 19/32 |
| 有限验证通过但私有行为评分错误 | 5/32 | 5/32 |
| 未解决 | 8/32 | 8/32 |

双方正确的 19 对中，adaptive 总成本更低 7 对，from_scratch 更低 12 对，
无平局。此比较是成功条件化的成本分布；另 13 对不能丢弃，也不能把失败
时的较低支出当作提效。结果不支持“旧模型复用稳定获益”的结论，需要将
参考模型误导、负迁移和拒绝复用纳入后续分析，而不是削弱从头基线。

执行/审计通过并不等于理论正确：64 次公开运行可以全部合法，仍存在上述
错误提案。最终报告必须同时列运行合法性、行为错误、未解决及覆盖率。

运行产物包含 config、完整 run、events、版本快照、独立 audit、两个私有
评测表，根目录包含 registration/report；每轮 450 个确定性文件，另有
manifest 和不参与比较的 timing。跨平台/重复运行的最终核验记录另存于
`runs/paid-transfer-cross-platform-verification-v1.json`，仅在它存在且验证器
通过时确认三轮一致，不把本页文字当作独立证据。

```powershell
uv run pytest research/adaptive_automata -q
uv run python scripts/run_paired_transfer_development.py --output runs/<新目录>
powershell -NoProfile -File scripts/verify_paid_transfer_development.ps1
```
