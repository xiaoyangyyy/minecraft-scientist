# Minecraft Scientist 阶段研究报告

## 研究问题与范围

项目检验智能体能否从不带语义名称的对象和干预结果中恢复可执行机制、
检测规则改变、修订理论，并将重复程序压缩为可复用符号。
当前证据支持有限候选空间中的结构化机制发现。真实像素感知闭环仍待验证。

## 方法

公开观测和动作经过 opaque ID 接口；隐藏规则由评测器持有。
工具关系、机器协议和资源转换使用有限版本空间，干预淘汰不符合观测的候选。
独立验证后理论进入注册表；预测失败触发异常检测与重新学习。
符号在额外世界中验证，验证实验计入预算。

外部模型比较使用相同目标世界证据。Voyager-style 条件额外接收源世界提取的
文本记忆，因此它是迁移条件，并不代表原版 Voyager 的完整实现。
符号后验具有预先定义的候选空间，结果不能外推到开放机制发现。

## 外部模型比较

20 对世界，目标 seed 为 1、3、…、39；每个机制最多 6 次证据干预。
指标为候选干预上的精确预测准确率，区间为跨世界的正态近似 95% 区间。

| 方法 | 平均准确率 | 标准差 | 95% 区间 |
|---|---:|---:|---:|
| DeepSeek context-only | 0.8000 | 0.0958 | [0.7580, 0.8420] |
| DeepSeek 文本记忆迁移 | 0.7280 | 0.1458 | [0.6642, 0.7919] |
| 符号版本空间后验 | 0.9646 | 0.0244 | [0.9540, 0.9753] |

正式成功运行包含 63 次调用及 305,554 tokens；其中 3 次为重试。
该运行的保守成本估计为人民币 0.9877 元，未包括此前失败尝试和 smoke run。
证据文件：`runs/deepseek-expanded-baselines/expanded-external-llm-baselines.json`。

## 配对消融

10 个 seed，各条件上限 80 次干预；比较同一 seed 的差值。
相同上限不代表实际使用相同实验数。

| 组件 | 平均效果 | 解释 |
|---|---:|---|
| 主动信息增益 | 节省 0.4 次实验 | 区间 [-4.3402, 5.1402]，提效证据不足 |
| 理论修复 | 恢复 0.1481 准确率 | 10/10 修复，关闭后 0/10 |
| 符号库 | 描述长度减少 13 单位 | 每个参考运行产生 3 个符号 |
| 转换符号迁移 | 节省 8 次实验 | 执行源世界实际学到的程序 |
| 学习规划器 | 节省 0.7 次实验 | 区间 [-1.8813, 3.2813]，提效证据不足 |

随机条件仅抽取尚未测试且仍有信息的动作。理论修复消融保留异常检测。
迁移实验是固定转换协议候选集上的程序复用；它不能证明通用知识迁移能力。
证据文件：`runs/strict-ablations/ablation-matrix.json`。

## 视觉接入状态

适配器已支持 MineStudio 返回的 `image` 观测字典，reset/step 路径通过模拟器
回归测试。当前已安装 WSL Ubuntu 22.04、JDK 8、隔离 Python 3.11 和 MineStudio
1.1.6。真实 RGB 首帧及 select/interact/wait 适配器运行通过，保存了图像和事件。
这不构成感知准确率或视觉发现成功率证据。
GridVisualController 仅将画面分区映射为动作目标，不具备对象识别能力。

完成视觉阶段仍需要稳定的受控场景、对象感知和独立任务评测。
首次 creative 方块交互探针正常退出，但截图显示目标未稳定在准星前，
因此 ROI 差异不计为有效破坏证据。原始产物保存在
`runs/minestudio-interaction-probe`，需要先修复初始化与位置稳定性。

后续通过日志定位到 absolute-origin 区块未加载，改为在玩家已加载区块内建场。
`runs/minestudio-interaction-probe-loaded` 的静止对照 ROI MAE 为 0，交互后为
45.4381；人工检查前后截图确认目标方块消失。这是单个 creative 受控场景的
动作效果证据，不能替代工具等级、状态机、转换链的视觉发现评测。

在 seed 0 的空手/铁镐石头实验中，按图像区域变化拟合现有 ToolVersionSpace，
生成匿名 ID 的可执行 TheoryIR，并在运行 seed 2 前保存预测。独立验证两项均
命中，覆盖率 2/2，截图核验空手目标保留、铁镐目标消失；预测文件 SHA256
保持不变。证据：`runs/visual-theory-holdout-seed2/report.json`。
此结果仅为固定相机、20 帧、生存模式的探索性验证：对应身份由实验场景提供，
实验选择预先固定，阈值并非普适校准，不能宣称自主视觉科学发现已经完成。
后续解释器增加 `required_context` 范围校验；历史预注册文件保持原样不回写。

修正不可达目标先验并清除掉落物污染后，seed 7 主动实验实际测试了两个匿名工具；
系统形成唯一候选理论，再在 seed 8 前冻结预测。两项保留预测均命中，覆盖率 2/2。
四个发现/验证运行的手持物遥测全部通过，完整性审计确认预注册 SHA256 为
`381d48f5170f2914285d20b05298505d5826f6b78d8cb87691ee0b9a3277a873`。
证据：`runs/active-visual-discovery-seeds7-8/{report.json,integrity-audit.json}`。
截图人工检查也确认空手目标保留、铁镐目标消失。该结论严格限定为固定相机、
单一场景目标、生存模式和 20 帧攻击；物体身份仍由 fixture 绑定，不代表自主
对象识别。Windows 全量 108 项测试与 Linux 视觉相关 32 项测试均通过。

进一步的 seed 12/13 运行消除了“夹具直接装备工具”的捷径：夹具只把候选放入
快捷栏槽位，Agent 随后通过生产适配器对不透明槽位目标执行 `SELECT`，再执行
交互。独立审计确认 4/4 事件日志均包含成功选择、4/4 选择后装备轨迹正确，且
两项留出预测仍全部命中。冻结预测 SHA256 为
`6558fa9de4faa87f484c45213a12035320881f1bcac88a4273078ec63804ebd3`；证据位于
`runs/active-visual-agent-select-seeds12-13/{report.json,integrity-audit.json}`。
这加强了动作闭环证据，但候选身份和目标区域仍由 fixture 提供。

seed 22/23 又移除了固定中央目标裁剪：系统先删除 HUD/提示区域，再把世界视野
划分为匿名网格，逐格比较无操作控制漂移与干预变化。低幅背景漂移不会否决另一
稳定单元中的强变化；若不稳定单元本身出现阈值级变化则弃权。四次新实验的自动
定位产物、选择事件和装备轨迹全部通过独立审计，留出准确率与覆盖率仍为 1.0。
冻结预测 SHA256 为
`981759aef3c79308305f71db7477ede40719ac4c1896dd9edd6eaa0707d03d08`；证据位于
`runs/active-visual-persistent-region-seeds22-23/{report.json,integrity-audit.json}`。
发现器直接消费经过严格模式校验的定位产物，不再重新计算旧中央裁剪。
独立审计同时逐文件核对运行时清单与源码快照哈希，六个源码文件全部一致。
相邻变化格现在会合并为匿名连通区域；训练与留出区域相差一个边界格，但 IoU
为 0.857，通过预注册阈值 0.5。这里证明的是固定视角下的持久变化区域匹配，
仍不是任意视角下的对象身份。当前门禁为 Windows 119 项、Linux 43 项视觉测试。

随后加入相机专用 `LOOK` 原语；它只发送相机增量，不触发攻击或使用。seed 30–32
三位置套件在执行前冻结负 yaw、中心、正 yaw 三个目标位置和像素亮度 argmax
规则。系统分别执行 5 次不透明视角动作并保存三张候选图，3/3 均选择正确，
15/15 `LOOK` 转换合规。独立审计从 PNG 重新计算所有分数，核对事件、报告哈希、
预注册和 5 个源码快照，结果全部通过。证据：
`runs/camera-search-suite-seed30/{report.json,integrity-audit.json}`。这证明受控主动
视角搜索，但不等于自然场景目标检测或路径规划。当前门禁更新为 Windows 122
项、Linux 48 项视觉测试。

随后加入带显式持续帧数的 `MOVE` 原语。seed 49–51 的预注册走廊套件只向 Agent
暴露一个不透明移动句柄；私有控制器将其映射到前进动作，策略仅根据 RGB 中央区域
分数决定是否继续。3/3 真实 MineStudio 实验均在第一个阈值交叉处停止，各执行 7 次、
每次 4 帧的移动。隔离的评估器坐标通道测得每次位移 7.504 格；包装器在适配器前
剥离位置字段，RGB 控制器发现残留字段会直接失败，因此坐标不进入 `Observation`、
`TransitionRecord` 或 Agent 事件日志。独立审计同时确认原始评估通道确实存在坐标、
公开通道确实无坐标，并从 PNG 重算全部分数，
核对首次阈值交叉、MOVE 数量/持续时间/合规性、位移、报告与预注册哈希以及 5 个源码
快照，全部通过。证据：
`runs/navigation-suite-seed49/{report.json,integrity-audit.json}`。这证明受控直线走廊
视觉接近，不等于多方向导航、避障或路径规划。当前门禁为 Windows 128 项、Linux
54 项视觉测试。

## 可复现入口

```powershell
uv run pytest
uv run minecraft-scientist benchmark --suite mvp --seed 0
uv run minecraft-scientist benchmark-ablations --seed 0 --seeds 10
uv run minecraft-scientist check-minestudio-backend
```

消融需安装训练 extra。外部模型实验另需凭据及显式成本开关；其模型输出不能
承诺跨调用字节一致。默认离线算法的确定性应与外部服务的可重复统计结果区分。
运行产物保存在 Git 忽略目录，分享研究结果时须同时提供对应 JSON 与调用账本。
