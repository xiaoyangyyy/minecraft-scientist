# 按泄漏组配对的研究分析：实现与证据

日期：2026-10-10。设计契约见 [group-analysis-design.md](group-analysis-design.md)。
本阶段是开发诊断工具，不是正式统计预注册、方法创新证明或完整框架验收。
首个开发组的结果在设计前已经公开，不能回溯称为未见／封存分析。

## 新增能力

在完整源／输入冻结和公开优先／独立原始表审计之后，才对评分行做分析。
入口必须实际调用完整源验证器，若提供验证配对也调用其完整验证器；不以
用户传入 valid、旧摘要或 rehash 后的伪造报告替代实际审计。分析后重新检查
输入及源码哈希；不覆盖输出，也不从半成品产生完成 manifest。

按泄漏组内实例平均，再对组等权；同时另列实例权重总数／均值和每组大小。
四个发现方法的全部六种两两对比、四法各自的两验证策略对比全部保留，不
挑赢家。主分母包括错误晋升、未晋升、未解决、有界无异常及不符合尾验证
入口的实例。旧模型不存在不当作正确或错误模型；候选拒绝的未评分部分也
独立保留。报告复位、原子动作、已报告失败、真实前缀／尾部费用及变异计算。

全部条件、H 内行为变化与否、重命名、目标行为是否已被公开旧族覆盖和构建
单编辑族内／外分层全部输出，空层不删除。公开族覆盖是无界确定性 reset
行为等价，不是字符串或物理结构相同；构建单编辑族不是学习器 DSL 的完整
召回证明。配对分析从完整已审计源取得这些上下文，不能静默省略或替换。

重采样对象是整个配对组向量，不把方法臂／实例独立重抽。默认 5000 次、
seed 20261010，一组时不报组间不确定性范围；观测零组间方差明确标注而不
宣布总体零方差。探索性百分位范围依赖组独立／可交换假设，泄漏隔离并不
自动证明该假设。不给自动显著性、方法优越性或创新结论。

计时单独存为非确定性产物，既有计时不含完整编排／存储，验证配对继承而
非重新执行发现搜索；不制造缺失的完整科学计算／API费用。抽样工作上限
耗尽时失败，不减少实例、组或重复次数来产生通过报告。
