# 随机理论的行为等价：实现与完整证据

日期：2026-10-10。契约见 [stochastic-equivalence-contract.md](stochastic-equivalence-contract.md)。
沿用单一 TheoryIR，以精确有理数可达线性空间判断两个公开随机程序的全部
有限字序列分布是否相同；不把查询长度上限内未找到差异当作全局不可区分。
这是已有加权自动机方法的实现，不是未知结构学习器或原创定理。

## 实现及独立检查

支持显式当前潜状态信念和允许动作子集，默认是初始模型信念／全部动作。
不隐式 reset；空动作作用域与完整动作域不能混用。证据绑定模型、信念和
调用方指定作用域，拒绝篡改为更容易成立的上下文。

不等价返回动作序列、具体输出事件及双方精确概率；等价返回实际可达基与
其前缀。独立检查器从原始 IR 分支重建概率，不调用搜索器、增量基代码或
编译预测／过滤／序列函数。对等价证据独立做批量消元，核验初始向量包含、
可达性、独立性、终端值为零以及每个允许 action/output 算子的闭包。

测试覆盖 12 对独立生成小程序与完整维数界枚举的一致性、超出四步的七步
反例、完全随机传感器遮蔽不同机制、状态重命名、当前信念／作用域绑定、
残缺／伪造证明、布尔整数和非约分概率、微小概率差及资源超限。初次收集
缺 research 根路径失败，按现有阶段模块的 bootstrap 契约修正。另一测试
错误地要求纯确定性 0/1 系数在一位限制下失败；改用真正的分数分支测试
位数超限，未缩小搜索空间或降低精度。中间 41／47 项只作开发证据。

新增九文件加不变的 236 依赖，共245源，逐项归档。Windows／Linux 冻结
合并随机执行、含噪声竞争及本模块各150项实际退出0，零失败／错误／跳过，
case 集一致；非主解释器整合／默认主包全量回归。

## 完整公开模型矩阵

双平台 CLI 及另行完整独立核验均实际退出0：两命名 seed，每组全部153对，
共306证明、616确定性逻辑产物／618物理文件。逐个产物读回检查双层哈希、
解析内容、完整覆盖、当前源绑定和跨平台一致性；共同 manifest 为
`e4c019fb7e4431132af462f6b4243c2c6a3ad053f40e284eb532df7b40b8fe5e`。
这不是306个科学世界：没有读取私有选择／轨迹，物理试验数明确为0。

每个命名组18程序形成14行为类，6对完全等价、147对可区分。索引12／14／16
及13／15／17各为一类：在无需 activation 的给定机制下，三个控制器不能从
这些结果分布归因。它不证明其他真实控制器或实际环境同样不可识别。
已返回见证长度为1／3／4／5／6，对应81／36／22／6／2对。未认证最短或
最低费用，不能由返回五步／六步见证反推所有短序列都无区分力。
不会因等价分组把类改为均匀先验；保留原模型组合先验的总质量。

见 `runs/stochastic-equivalence-public-cross-platform-verification-v1.json`。

最终清单。搜索计数与审计计数分别记录，前者未独立重跑认证。
