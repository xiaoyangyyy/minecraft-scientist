# Paired structural development diagnostics: analysis contract

Date: 2026-10-10. This analysis is designed after the first group's results were
already observed. It is not retrospective "pre-registration", a formal holdout
analysis or proof of method novelty. The full 27-group process is still running;
no partial scores or sealed tuning/evaluation fixtures choose this protocol.

## Unit and denominator

Use the corpus's registered transitive leakage groups, not opaque IDs, renamings,
repeated runs or individual trajectories as independent samples. Report their
number and sizes. Within each group average fixture-level outcomes; then give
each group equal weight. Also retain fixture-weighted means/totals explicitly,
because they answer a different descriptive question. Leakage disjointness is
not proof of iid/exchangeable sampling or independent physical worlds.

Structural analysis includes every registered fixture and all four methods.
Validation analysis includes every fixture/method and both paid policies; its
main denominator never conditions on eligible tails or successful promotions.
Paired policies must have the same eligibility, paid prefix and no-anomaly
classification. Reject missing/duplicate rows and group/outcome contradictions.

Correct/wrong promotion, not promoted, unresolved, H-change, old correctness,
post-boundary detection, false/early anomaly, reset count, atomic action count,
reported dispatch failure and actual paid cost are distinct. "Undetected changed
at H" includes changed targets not reached inside completed monitoring; it is
not misnamed a within-window false-negative rate. Validation additionally shows
eligible tails, correct/wrong candidate rejection, prefix/tail cost and mutation
operations. Rejection may happen in the shared Wp prefix, not necessarily a new
challenger success. Not-promoted does not mean a correct recovered theory.
Absent old models are distinct from wrong old models and remain in the main
denominator. Rejected candidates with unavailable correctness are unscored,
not silently treated as either a correct rejection or a lost correct candidate.
The resampling work guard is 300 million weighted terms; exceeding it aborts
the analysis rather than filtering groups or silently reducing replication.

## Comparisons and exploratory ranges

Structural comparisons: all six unordered pairs of the four methods, never only
the comparison that wins. Validation comparisons: public_mutation minus
public_coverage, separately for all four discovery methods. Signed differences
are left minus right; higher is good for correct promotion but bad for wrong
promotion and cost, so no automatic combined improvement score is used.

All-data and every registered case, H-change/no-change, renaming, public-prior
behavioral coverage and construction one-edit-family stratum are reported,
including empty cells. Public-prior coverage is unbounded deterministic reset
behavioral equivalence, not program-syntax identity or unique physical factors.
The construction family diagnostic is not complete learner DSL coverage.
Validation inherits these contexts from the complete audited structural rows;
it cannot silently omit source context or substitute mismatched fixture facts.
Average paired fixture differences within a
group before comparing equal-weight groups. The diagnostic resamples whole
paired group vectors with replacement, not individual fixtures or method arms.
Default 5000 resamples, seed 20261010; use linear-interpolated 2.5/97.5 percentiles.
All metrics/contrasts in a stratum use the same deterministic draws. A single
group returns null uncertainty; zero observed between-group variance is flagged
and is not a guarantee of zero population variance.

These are exploratory percentile ranges under a stated exchangeability/
independence assumption, not familywise-adjusted confidence claims or p-values.
No statistical superiority or innovation conclusion is automatically emitted.
Formal primary endpoints, smallest meaningful effects, sample/power/precision
design, multiplicity control and sealed structural holdouts remain to be frozen
before any confirmatory run. The current 18 evaluation groups do not satisfy
that missing formal design merely because development has 448 named fixtures.

## Provenance, compute and gates

The runner pins manifests and source, invokes the actual complete independent
source verifier, then the complete validation verifier if supplied, before
reading scored report rows for analysis. Stored summaries or a user-written
"valid" receipt alone are insufficient. Input hash drift, partial artifacts,
source drift, unequal selections and exhausted resampling limits fail without
truncating evidence or creating a completion manifest. Output is a new directory.

Keep runtime separate/nondeterministic. Existing timings omit storage and full
orchestration; validation inherits discovery search rather than executing it
again. Reset/action/validation cost and mutation operations are not a complete
scientific-compute or API cost measure. Never manufacture missing costs as zeros.

Tests must cover independent arithmetic/reference checks, uneven groups,
renaming/repetition within groups, single-group/empty-stratum abstention, row
order determinism, all-negative outcomes, partial/missing/duplicated/retyped
rows, unequal paid prefixes, source/input drift and the mandatory audit barrier.
Real completed first-group runs check legacy totals; synthetic unit rows are
analysis fixtures, not additional independent scientific worlds.

The full H1/H2/H3/H4, strong random/LLM/adaptive baseline fidelity, unknown control
and noise, symbol/negative transfer, controlled Minecraft, natural RGB/navigation,
long recovery and integrated release scope remains unchanged and uncompleted.
