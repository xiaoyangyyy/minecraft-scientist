# 含噪声候选族失配：在线影子监测与证据边界

更新日期：2026-10-11。冻结协议日期为2026-10-10，见
[noisy-adequacy-contract.md](noisy-adequacy-contract.md)。
本阶段针对完整含噪声开发实验中出现的族外高后验错误：候选之间的相对支持，
不能证明整个候选族包含正确解释。沿用单一 TheoryIR 和现有 Agent，不新增
另一套理论系统，也不把告警当作完成结构修订。

## 已实现的在线监测与独立核验

每个真实动作执行前冻结全部固定候选的输出分布和可预测均匀备择；执行后
更新完整历史似然。统计量为备择累计似然除以固定候选最大累计似然，不用
先验混合分母，也不允许每一步自由更换最大似然模型。复位只清空潜状态，
保留累计似然、显著性预算和首次拒绝证据。所有候选均保留，只有不可能的
历史前缀可以在后续预测中跳过。没有拒绝不等于模型充分或理论正确。

这是已有 [Universal Inference 第8节](https://arxiv.org/pdf/1912.11436) 的
序贯似然构造，不是新统计理论。每轨迹 alpha=1/20 的条件性界依赖至少一个
固定候选的完整条件输出／控制／复位律正确，以及动作与备择可预测；固定
PRNG 回放通过不能证明真实世界满足该概率律。该 alpha 不构成全部30次、
新增版本／语言／时期的同时风险保证。

影子监测不把结果回传规划器、不修改先验、预算或实际动作，也不在拒绝后
停止采样。保留原后验错误及所有成本，才能测量真实检测能力而非因提前停止
或额外证据获得表面收益。首次告警按实际动作和复位成本记录。还没有理论
注册表变更、未知结构生成或新理论晋升，accepted_theory=null 不算零错误修订。

独立核验从原始 IR 分支重建携带完整前缀似然的未归一化状态向量；不调用
监测器更新、编译预测／过滤或 Bayes 更新。检查每个执行前预测、累计似然、
复位、统计量、首次拒绝成本及全部公开回执。原公开策略审计与此核验全部
完成后，才对任何选中的私有原始世界评分。复用的 schema、作用域文字与
原策略检查器明确列出，不把共享校验说成完全独立实现。

新增失败测试让动作已经实际执行、随后似然更新失败，确认完整冻结预测、
真实 TransitionRecord、原始派发及两份部分账本保留，不生成完成清单。
源码漂移在源生成结束和独立核验结束都检查；存储失败保留已经存在的字节，
不承诺无法完成的额外写入。计时为实际 Agent 与在线监测共同成本，在写盘前
结束，不含存储／审计，也不是监测器独立边际开销。
